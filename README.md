# To-Do App

A simple browser-based To-Do application built with HTML, CSS, and JavaScript.

## Features
- Add tasks with due dates and priority
- Mark tasks as completed
- Delete tasks
- View active and completed tasks

## Run locally
Open `index.html` in a web browser.

## Run with Docker
Build the image:
docker build -t todo-list-app:latest .

## Technologies
- HTML
- CSS
- JavaScript
